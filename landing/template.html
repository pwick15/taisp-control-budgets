Chapter 1 · The checkpoint

Every program passes a knight before it runs

This is trusted monitoring, the setup from Greenblatt et al.'s AI Control paper. Our "ninja" is a model that slips backdoors into otherwise correct code: a hidden input that makes the program give a wrong answer. Our "knights" are monitor models that score each program for suspicion.

1. Code arrives500 programming problems, each solved twice: once honestly and once with a backdoor.
2. A knight scores itThe monitor reads the code with comments removed and rates suspicion from 0 to 10.
3. The top 2% get auditedHumans can only check a few programs. Only the most suspicious 2% reach them.
4. Everything else runsA backdoor counts as caught only if it lands in that audited 2%.

Chapter 3 · The duel

Chapter 5 · Power up

More thinking catches more backdoors, without more false alarms

Reasoning effort is how long a model may think before it answers. Pick a knight and turn the dial. For six of the eight models we tested, more effort raised the catch rate. The false-positive meter barely moves for any of them.

Chapter 6 · The squeeze

When humans can check less, Sonnet pulls ahead

At a 2% audit budget the two leaders are close. Real teams often can't review 2% of everything an AI writes. Drag the budget down and watch the gap open.
